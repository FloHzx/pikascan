# PikaScan — Flux d'annonces, branding, mobile (MàJ 3 nov. 2026)

- **Push** : Flo travaille avec un clone local (`...\Documents\GitHub\pikascan`) et pousse lui-même via GitHub Desktop ; l'assistant modifie les fichiers du dossier local.
- **Branding** : logo Poké Ball développé (viseur + faisceau de scan), titre « PikaScan », bandeau d'intro compact et fermable. **Mobile** : refonte lisible ≤ 560 px (fiches en colonne, graphiques adaptés). Sélection par cases retirée.
- **Onglet Flux** (`#panel-flux`) : annonces à évaluer (verdict = mêmes règles que « Ma base » : décote, frais, marge cible). Ajout manuel (coller titre/lien) ou automatique depuis `data/annonces.json`. Filtres À traiter / Bons plans / Suivies / À confirmer / Ignorées, badge d'alerte.
- **Pipeline automatique** (pas de scraping direct de Vinted : interdit par ses CGU) : tâche Apify (service tiers, au risque de Flo) → GitHub Action `.github/workflows/annonces.yml` (cron 5 min) → `scripts/pull_annonces.mjs` → `data/annonces.json` → lu par l'appli. Secrets : APIFY_TOKEN (+ NTFY_TOPIC pour une notif push gratuite). Variables : APIFY_TASK, MAX_PRICE, TARGET_MARGIN, MODE (good|all), PHOTOS (off pour ne lire que les titres).
- **Analyse des photos** (`scripts/photo_engine.mjs`) : Chromium sans écran (Playwright) ouvre l'appli et réutilise le scanner « Par l'image » (`window.__ocr`) sur 1 à 3 photos par annonce. Décision : carte seule (titre + photo concordent ; la photo contredit le titre → écartée) ou lot (somme des cartes reconnues ≥ 0,30 €, non lues comptées 0 €, alerte si valeur > 8× le prix). Le lecteur n'est installé dans l'Action que s'il y a de nouvelles annonces (`pull_annonces.mjs --count`).
- **Limites** : testé sur images de test, pas encore sur de vraies annonces Apify. Cartes Dresseur peu contrastées souvent non lues ; photos floues, reflets ou forte perspective moins fiables ; fausses cartes non détectées.
- **Côté Flo** : compte Apify + tâche de recherche Vinted planifiée ; secrets/variables GitHub ; workflow `annonces.yml` dans `.github/workflows/`.
